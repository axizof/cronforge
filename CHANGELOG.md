# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and versions follow
[Semantic Versioning](https://semver.org/). Entries after 1.0.0 are generated by
release-please from the commit history.

## 1.0.0 (2026-11-02)

First public release.

- `parse` / `tryParse`, `validate`, `describe`, `nextOccurrences`, `build` / `buildResult`
  and `registerLocale`.
- Standard cron (5 fields, macros, 7 = Sunday) and Quartz (6–7 fields, `?`, `L`, `L-n`, `LW`,
  `nW`, `nL`, `n#m`, `V/N`).
- Descriptions in English, French, Spanish, German and Italian, also published as JSON under
  `cronforge/locales/<code>.json`.
- Timezone-aware iteration with a defined DST policy.
- ESM and CommonJS builds with type definitions, no runtime dependencies.
